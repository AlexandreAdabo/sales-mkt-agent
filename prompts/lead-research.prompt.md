# Pesquisa de empresa

Analise somente os dados fornecidos. Não presuma nem complete CNPJ, telefone, WhatsApp, site, porte ou qualquer outro fato ausente. Use `null` para dados que não possam ser confirmados.

As dores e oportunidades devem ser apresentadas como hipóteses, nunca como fatos, quando não houver evidência direta. Preserve o nome e os dados de origem. Produza exclusivamente o objeto solicitado pelo schema JSON.
